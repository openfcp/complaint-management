# 话术模板库

配合 `negotiation-support.md` §4「实时话术引导」使用。按谈判五阶段（破冰 → 共情 → 议题转换 → 方案协商 → 闭环确认）及合规场景分类，共六类。

## 使用规则（先读）

1. **三步用法**：识别当前谈判阶段 → 从对应类别选 1-3 条 → 填入案件变量后做合规校验，再交给人工选用。
2. **变量占位**：`【客户称谓】`「【产品名称】」「【金额】」「【时限】」等方括号内容必须按案件事实填充，不得原样输出给客户。
3. **强制人工确认**：所有话术仅为建议稿，向客户表达前须由处理人员确认事实、权限与合规性。
4. **机构适配**：话术须按本机构产品、流程、授权口径调整，使用前经消保与法务审核后方可纳入正式话术手册。
5. **禁止自行创造承诺**：话术中不得出现无制度依据的赔偿承诺、无权限的时限承诺、对监管处理的预测性表述。

## 1. 破冰（开场 30 秒）

**适用**：首次接触、客户情绪尚可控、需建立沟通基础。

| 场景 | 参考话术 | 要点 |
|------|---------|------|
| 首次致电 | 「【客户称谓】您好，我是【机构名称】【部门】的【姓名】，工号【工号】。您反映的【事项】我已完整看过记录，今天这通电话就是想跟您把情况核实清楚，也把能做的处理方案跟您说透。」 | 自报身份+工号，先给"已看过材料"的信号 |
| 客户已在网点等待 | 「让您专门跑一趟，我先跟您把时间安排说清楚：今天大约需要【时长】，我会把【事项】的处理路径和节点都告诉您。」 | 先管理预期，降低对抗 |
| 客户为二次来电 | 「上次是【同事/姓名】跟您沟通的，我这边已经看到【日期】的沟通记录，不用您再重复一遍，我们直接说还没解决的那部分。」 | 避免客户重复叙述，直接展示连贯性 |
| 客户拒绝沟通 | 「理解您现在不想多聊。我只说一句：【核心结论】。您什么时候方便，我随时按您的时间再联系。」 | 不纠缠，留出退出通道 |

## 2. 安抚（情绪疏导）

**适用**：客户情绪激动、投诉升级、出现指责或威胁投诉监管。

| 场景 | 参考话术 | 要点 |
|------|---------|------|
| 情绪激动 | 「这件事换作是我，我也会着急。您先说说最让您不放心的是哪一点，我一条一条记下来。」 | 先接情绪再接事实，避免"您别激动" |
| 客户认为被推诿 | 「之前几次沟通没让您得到明确答复，这是我们做得不到位。今天我不给您"再等等"这种话，我给的是【具体结论/节点】。」 | 承认体验问题，不评价前手对错 |
| 客户提及投诉监管 | 「向监管部门反映是您的权利，我不会拦您。同时我这边该做的处理不会停，【具体动作】我今天就推进。」 | 不劝阻、不恐慌、不承诺监管结果 |
| 客户提出高额索赔 | 「您提的【金额】我记下了。我需要按【依据】核对责任和权限，核对完我会明确告诉您能处理到什么程度，不含糊。」 | 不现场答应也不现场否定 |
| 客户情绪失控/辱骂 | 「我理解您在气头上。我们先把事情解决，人身攻击的话我先不计较，但如果继续这样，我只能先结束这通电话，稍后再联系您。」 | 设定边界，保留录音与记录 |

## 3. 议题转换（从情绪转向事实）

**适用**：情绪初步平复，需进入事实核对与责任界定。

| 场景 | 参考话术 | 要点 |
|------|---------|------|
| 从情绪转事实 | 「我把您说的情况按时间顺序理一遍，您听听有没有出入：【时间线】。」 | 用复述建立"被听见"感，同时校验事实 |
| 客户诉求发散 | 「您提了【A】【B】【C】三件事，我建议先解决【A】，因为它影响【后果】；另外两件我单独建单跟进，不会漏。」 | 拆分议题，避免一次谈崩 |
| 客户与机构事实不一致 | 「您记得是【客户版本】，系统记录显示是【系统版本】。这个差异我需要调【录音/合同/日志】来核对，核对完给您答复。」 | 用凭证而非争论解决分歧 |

## 4. 方案协商（三策落地）

**适用**：事实已核对，进入方案提出与让步交换。

| 场景 | 参考话术 | 要点 |
|------|---------|------|
| 提出上策 | 「按我们核对的【依据】，这件事我们确有【责任点】。我能给到的方案是【方案】，【时限】内落地。」 | 先给依据再给方案，方案可执行 |
| 提出中策 | 「您希望的【诉求】和我能批的【权限】之间还有差距。我建议这样：【折中方案】，另外我帮您争取【增值措施】。」 | 明确差距来源，用非现金资源补位 |
| 客户不接受 | 「这个方案不是我在压您，是【依据/权限】决定的。如果您认为还有空间，我给您两条路：【复议路径】【调解路径】。」 | 把"拒绝"转成"路径选择" |
| 需提级审批 | 「您这个诉求超出我的审批权限，我需要提级审批。审批期间请您先不要通过其他渠道重复提交，我【时限】内给您明确答复。」 | 标注"此方案需上级确认后方可提出" |
| 让步交换 | 「如果我帮您争取到【让步项】，您这边能否接受【交换条件，如撤回重复投诉/配合补充材料】？」 | 让步必须有对价，不做无条件退让 |

## 5. 引导调解（僵持出口）

**适用**：金额争议 3 轮以上未果、责任各执一词、客户拒绝所有方案。

| 场景 | 参考话术 | 要点 |
|------|---------|------|
| 建议第三方调解 | 「我们双方对【争点】的理解确实不同。与其继续各说各话，不如引入【调解组织/行业协会】做中立判断，结果双方都得认。」 | 强调中立性，不暗示"机构怕调解" |
| 客户担心调解耗时 | 「调解不是把问题拖长，是把争议点固定下来。我这边材料【时限】内备齐，不让您等我们。」 | 给出机构侧的配合承诺 |
| 客户坚持诉讼 | 「诉讼是您的权利。我只提醒一点：您现在手上的【材料】建议先留存好，我这边该提供的【凭证】会按程序给您。」 | 不劝阻、不施压、保留配合姿态 |

## 6. 合规拒绝（无责或不合理诉求）

**适用**：经判定无责、诉求超出合同与法规范围、涉嫌恶意投诉或黑灰产代理。

| 场景 | 参考话术 | 要点 |
|------|---------|------|
| 无责拒绝 | 「按【合同第X条/法规第X条】的约定，这项【诉求】不在我们责任范围内，所以无法按您的要求处理。这一点我必须如实告诉您。」 | 引用条款原文，拒绝理由可核验 |
| 诉求超范围 | 「您要求的【诉求】目前没有对应的制度依据，我无法承诺。但【替代方案】在我的权限内，您看是否接受。」 | 拒绝的同时给出可行替代 |
| 疑似代理投诉 | 「我们可以正常受理您的诉求，但需要您本人确认【授权/身份】信息。代理机构收取费用前，建议您先核实其资质。」 | 不指控、不拒办，提示风险并核验身份 |
| 重复投诉施压 | 「同一事项我们已在【日期】给出结论【结论】。如果您有新的证据，我立即重新核查；没有新证据的话，结论不会因为投诉次数改变。」 | 口径稳定，不因施压而松动 |

## 7. 通用禁忌（违反即视为话术事故）

- 不说「这是规定」「上面就这么定的」——必须给出条款依据与责任主体。
- 不与客户争辩对错、不评价客户动机、不评价监管机构。
- 不承诺无制度依据的赔偿、不承诺无法保证的时限。
- 不透露其他客户信息、不透露内部处理人员评价与问责情况。
- 不在电话中确认客户银行卡号、密码、验证码等敏感信息。
- 不对客户说「你告也没用」「随便你去投诉」等激化表述。
