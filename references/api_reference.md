# 工具与输入输出规范

## 1. 输入规范

| 输入类型 | 格式要求 | 必填/选填 |
|---------|---------|----------|
| 投诉原始数据 | CSV/Excel/数据库查询结果，字段至少包含：投诉时间、投诉渠道、投诉业务类别、投诉原因、客户类型、处理状态、处理时效 | 必填（分析类任务） |
| 分析目的 | 自然语言描述，如"分析本月投诉量上升原因" | 必填 |
| 数据口径 | 自收投诉/监管统计口径/监管通报口径，未指定则主动询问 | 必填 |
| 统计周期 | 如"2026年Q2""2026年6月" | 必填 |
| 对标基准 | 历史同期/全行均值/同业均值/监管要求 | 选填 |
| 机构经营数据 | 分行层面经营数据（用于对标分析） | 选填 |
| 外部数据 | 宏观经济数据（用于建模分析） | 选填 |

## 2. 输出规范

| 输出类型 | 格式 | 适用场景 |
|---------|------|---------|
| 分析摘要 | 自然语言段落（≤300 字） | 简要分析请求 |
| 统计报表 | Markdown 表格 | 描述性统计、对标分析 |
| 趋势图表 | 图表描述 + 数据表（宿主平台支持时生成图表，不足时降级为数据表） | 趋势分析、分布分析 |
| 交叉矩阵 | Markdown 表格 | 多维交叉分析 |
| 根因报告 | 结构化文档（问题→证据→根因→建议→跟踪） | 诊断性分析 |
| 预警报告 | 结构化文档（信号→阈值→等级→建议） | 预测性分析 |
| 完整分析报告 | 五部分框架结构化文档 | 月报/季报/专项报告 |
| 建模分析报告 | 结构化文档（技术路线→数据→模型→结果→局限性） | 建模类任务 |

## 3. 工具依赖

### 数据处理（分析类任务）

| 工具类型 | 用途 | 必要性 |
|---------|------|-------|
| 表格处理 | 读取 CSV/Excel 投诉数据，执行统计计算 | 必须 |
| 数据透视/聚合 | 按维度分组统计、交叉矩阵计算 | 必须 |
| 图表生成 | 趋势图、分布图、对标图 | 建议（能力不足时降级为数据表） |
| 统计计算 | 均值、标准差、环比、占比、条件概率 | 必须 |

### 建模（建模场景）

| 工具类型 | 用途 |
|---------|------|
| Python 统计库（pandas/numpy/scipy） | 基础统计、因子分析、聚类分析 |
| statsmodels | 时间序列分析、格兰杰因果检验 |
| scikit-learn | 聚类、回归建模 |
| 深度森林实现（gcForest） | 投诉质量评估模型（高级场景） |

可用脚本：`scripts/complaint_stats.py`（投诉数据快速统计分析：指标计算、帕累托、环比、异常波动标记）。无表格工具时可用该脚本处理 CSV/Excel。

## 4. 异常处理与兜底

### 数据不足

| 场景 | 处理策略 |
|------|---------|
| 用户未提供投诉数据 | 明确告知需要的数据字段和格式，给出 §1 的字段模板 |
| 数据字段缺失 | 告知缺失字段对分析维度的影响，建议补充或调整分析范围 |
| 数据量不足 | 告知最低数据量要求（至少 3 个月数据才能做趋势分析），建议补充或降级分析方法 |

### 超出能力边界

| 场景 | 处理策略 |
|------|---------|
| 实时流式分析 | 告知当前为批量分析 |
| NLP 语义自动分类 | 告知当前支持基于已分类数据的分析 |
| 跨机构数据整合 | 告知需统一口径格式，当前支持单机构分析和对标 |

### 置信度不足

按 `compliance-safety.md` §5 降级机制执行。
