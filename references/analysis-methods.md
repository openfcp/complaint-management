# 投诉分析方法论（四层价值链 + 多维交叉 + 建模）

## 1. 关键指标体系

| 指标类别 | 指标名称 | 计算公式 | 分析作用 |
|---------|---------|---------|---------|
| 规模 | 投诉发生率 | 投诉总量 / 有效客户数 | 消除客户基数影响，跨机构对标 |
| 规模 | 有效投诉量 | 剔除重复/无效后的投诉数 | 真实诉求规模 |
| 变动 | 环比增长率 | (本期量 - 上期量) / 上期量 | 识别异常波动 |
| 质量 | 有效投诉率 | 有效投诉量 / 投诉总量 | 区分有效诉求与无效/恶意投诉 |
| 质量 | 重复投诉率 | 重复投诉量 / 投诉总量 | 衡量首次处理效果 |
| 质量 | 升级投诉率 | 升级投诉量 / 投诉总量 | 衡量投诉管控能力 |
| 效能 | 首问解决率 | 1 - 回拨率 | 衡量一线处理能力 |
| 效能 | 48小时响应率 | 48小时内响应量 / 总量 | 衡量响应速度 |
| 效能 | 5个工作日结案率 | 5日内结案量 / 总量 | 衡量处理效率 |
| 效能 | 平均结案时长 | 结案投诉的平均处理天数 | 衡量整体效率 |
| 满意度 | 处理满意度 | 结果/时效/态度分项得分 | 衡量客户感知 |

所有数值必须注明口径和计算公式。

## 2. 描述性分析（发生了什么）

执行路径：
1. 口径确认（未指定则主动询问）
2. 三维同步分析：
   - **时间维度**：投诉量趋势、季节性规律、分布稳定性
   - **客户维度**：投诉客户画像（新客/老客、高价值/低活跃、年龄/性别/学历、特殊客群）
   - **渠道/场景维度**：投诉入口分布、服务旅程还原
3. 按指标体系计算各项指标，标注异常指标
4. 异常波动识别：基于历史均值和标准差，标记超出 ±2σ 的波动
5. 伪异常排除：三维交叉验证，排除客户基数变化等伪异常因素

输出规范：趋势数据用表格/图表呈现并标注统计周期和口径；异常指标必须附带初步归因（至少排除一个伪异常因素）。

## 3. 统计陷阱库（输出前逐项排查）

| 陷阱类型 | 问题描述 | 规避方法 |
|---------|---------|---------|
| 口径混淆 | 不同口径数据直接对比 | 每项分析明确口径，不可混用 |
| 率与量混淆 | 发生率最高 ≠ 投诉量最大 | 同时看"率"（风险定位）和"量"（影响定位） |
| 总量掩盖结构 | 总量持平但内部结构剧变 | 必须做结构拆解 |
| 均值掩盖分布 | 平均值达标但长尾严重超时 | 看分布（P50/P90/P99） |
| 相关即因果 | 同步变化不等同因果 | 用格兰杰因果检验等方法验证 |
| 服务态度分类误导 | "服务态度"投诉实为利益争议 | 二次分类还原真实诉求 |

## 4. 诊断性分析（为什么）

执行路径：
1. **高频高权重识别**：从描述性结果筛出占比异常高或增长异常快的投诉类别
2. **二次分类**：对筛出类别重新细维度打标（如"服务态度差"拆解到"理财亏损后施压""费用争议中情绪化表达"）
3. **跨部门数据对照**：投诉记录与业务事件时间轴叠加（系统故障记录、产品发布时间、促销活动时间轴、政策调整生效节点）
4. **根因定位**三法：
   - 时序对照法：投诉时间序列与业务事件时间轴叠加，识别滞后关联
   - 分层剥洋葱法：粗分类逐层深入到细分类，每层追问驱动因素
   - 5-Why 追问法：连续追问 5 层直至触及可行动的根本原因
5. **根因检验**：结论能否指向具体责任节点和可采取的行动

**根因结论表述规范**：
- 禁止"废话型"："产品质量问题占比高，需加强质检"
- 合格"根因型"："当班产线主管交接记录缺失导致的漏检，发生在周五下午换班时段，频率是其他时段 3.2 倍"

**根因归因漏斗法**（三层归因判定）：

| 归因层级 | 判定条件 | 归因结论 | 整改方向 |
|---------|---------|---------|---------|
| 一层传递 | 投诉集中在特定分行/网点，其他机构无此问题 | 执行层问题 | 自查该机构销售话术差异与 KPI 考核导向 |
| 二层传递 | 投诉散布多分行，但集中在特定客群（如老年群体） | 产品适配层问题 | 产品适老化/条款复杂度/信息披露清晰度 |
| 三层传递 | 凡购买该产品的客户均有投诉，不分机构和客群 | 产品本身问题 | 总行层面优化产品定价/流程/到账时效 |

## 5. 预测性分析（会怎样）

1. **规律识别**三类：
   - 周期性规律：固定时段的投诉波动（如长假前后物流投诉上涨）
   - 滞后性规律：业务事件与投诉响应的固定时滞（如大促结束后 5-9 天使用问题类投诉集中爆发）
   - 概率性规律：条件概率（如首次投诉处理后 72 小时无跟进，二次投诉概率显著上升）
2. **预警模型**：信号识别 → 阈值设定 → 分级响应 → 动态校准。常用阈值：环比增长超 5% 黄色预警、超 10% 红色预警（阈值须标注概率分布依据）
3. **时序预测**：基于 3-6 个月滚动投诉量，一阶/二阶移动平均构建预测基线；趋势预测纳入宏观经济变量（GDP 增速、M1/M2）

输出规范：每个规律必须标注数据周期和样本量；必须附带局限性说明（黑天鹅不可预测、新业务缺历史参照、模型需持续校准）。

## 6. 指导性分析（该怎样）

1. **资源优先级配置**：基于分析结论对改善方向排序，排序基于数据而非主观判断
2. **ROI 评估**：
   - 预期收益 = 预期投诉降低量 × 单件投诉处理成本
   - ROI = 预期收益 / 改善方案实施成本
3. **决策复盘框架**：预测 vs 实际、建议 vs 执行、执行 vs 效果三维对比；复盘跟踪指标、频率、责任部门明确标注

## 7. 多维度交叉组合分析

**单维度拆解（基础层）**：
- 客户维度：类型、资产等级、特质、特殊客群
- 产品维度：按 JR/T 0169 业务类别，运用"发生率漏斗法"+"贡献率漏斗法"（二者必须同时使用，互补）
  - 发生率漏斗：通过投诉发生率筛高风险产品，经客户→分行→产品三层逐步聚焦
  - 贡献率漏斗：通过投诉贡献率筛规模大的产品，经分行→客群→产品三层逐步降量
- 经营维度：分行投诉分析用**双对标四象限法**——同时与全行平均水平和自身历史水平对比，划分四个管理象限，避免一刀切管理

**交叉组合（进阶层）**：

| 交叉组合 | 发现能力 | 使用顺序 |
|---------|---------|---------|
| 客户 × 产品 | 哪类客户在哪类产品上投诉多 | 第一层 |
| 客户 × 渠道 | 哪类客户通过哪个渠道投诉多 | 第一层 |
| 产品 × 原因 | 哪类产品因什么原因投诉多 | 第二层 |
| 分行 × 产品 × 客户 | 精准干预靶点 | 第三层 |
| 时间 × 产品 × 原因 | 时序 + 根因 | 第三层 |

操作规范：先确定分析目的 → 选最相关的 2-3 个核心维度 → 构建交叉矩阵识别异常单元格 → 对异常单元格加维度拆解 → 输出"分行+客群+产品+原因"精准靶点。遵循"从少到多"，不直接使用 4 维以上交叉。

## 8. 帕累托分析

按投诉原因维度统计频次 → 降序排列 → 计算累计占比 → 标记累计占比达 80% 的原因集合为"核心根因集" → 输出帕累托图及核心根因清单。核心根因集每项进入 §4 三层归因判定。

## 9. 高等数学建模（按需启用）

适用条件：用户明确要求建模，或精度需求超出描述性/诊断性方法能力。

| 分析目的 | 推荐技术 | 适用场景 |
|---------|---------|---------|
| 因果方向判断 | 格兰杰因果检验 | 变量间时序引导关系 |
| 影响权重量化 | 因子分析 | 多指标中提取关键因子并量化权重 |
| 未来趋势预测 | 时间序列分析 | 历史时序规律外推 |
| 机构分组建模 | 聚类分析 | 消除内生性，分组内建模 |
| 高维特征降维 | 局部线性嵌入（LLE） | 保持非线性结构降维 |
| 评估模型构建 | 深度森林（级联森林）+ 多粒度扫描 | 小数据集稳定建模 |
| 计量工具 | Eviews | 计量经济学标准化工具链 |

**标准建模路线**：数据采集 → 降维（LLE）→ 因果检验（格兰杰）→ 影响量化（因子分析）→ 分组处理（聚类）→ 预测建模（时间序列/深度森林）→ 结果校验

输出规范：
- 说明技术路线和模型假设
- 报送质量评估使用四维度指标因子：客户结构、机构影响力、产品质量、服务能力/服务资源
- 趋势预测纳入宏观经济变量
- 注明置信区间和局限性；R² 偏低或置信区间过宽时主动说明解释力不足

## 10. 假设检验支持

- 双比率检验：如"新版 APP 上线后投诉率是否显著高于上线前"，输出 P 值（P<0.05 差异显著）
- 卡方检验：如"不同产品线的投诉与分支机构是否独立"，输出统计量和结论
- 结果自动附数据样本说明和注意事项
