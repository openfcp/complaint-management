# 制度管理与监管对标

定位：Agent 承担信息比对和初稿生成等重复性工作，不替代制度审批决策。

## 1. 制度起草辅助（4W1H 框架）

流程：管理岗输入制度类型（总括/专项）和适用范围 → 生成 4W1H 大纲（Who/What/When/Where/How）→ 大纲确认后逐章节填充内容 → 每处引用法规库对应条款作为依据 → 生成完整初稿 → 管理岗逐段审核 → 提交审批。

制度体系参考："1+N"制度体系（1 个总括制度 + N 个专项制度）。

## 2. 法规变更影响分析（新规比对，强制格式）

触发：监管新规发布或修订征求意见稿出台。

流程：获取新规全文 → 与现行内部制度逐条比对 → 识别三类差异 → 生成《法规变更影响分析报告》→ 推送管理岗。

**每条差异必须包含**：
1. 新规条款编号及原文
2. 现行制度对应条款编号及原文
3. 差异类型：新增（新规有但制度无）/ 修订（条款不一致）/ 废止（新规取消的原有要求）
4. 影响评估：高 / 中 / 低
5. 修订建议（低影响差异仅列出，不生成修订建议）

监管期望参考：新规"5 个工作日完成解读、15 个工作日完成发布"。

## 3. 制度版本管理

每次修订记录版本台账：版本号 / 修订日期 / 修订内容摘要 / 修订依据 / 审批人 / 生效日期。各岗位查看制度时默认展示最新生效版本，历史版本可追溯。

## 4. 合规缺口检测

每季度主动扫描现行制度库与法规库匹配度（不依赖法规变更触发）：
- 制度条款与最新法规不一致
- 制度未覆盖新规要求

输出《合规缺口清单》推送管理岗。

## 5. 常用监管依据速查

| 监管文件 | 关键约束 |
|---------|---------|
| 《银行业保险业消费投诉处理管理办法》（2020 年 3 号令） | 处理时限 15/30/60 日；告知义务；回避制度；档案保存 ≥ 3 年 |
| 《金融机构消费投诉处理管理办法（2025 征求意见稿）》 | 溯源整改；黑灰产打击；调解衔接；适用范围扩展 |
| JR/T 0169-2018 | 投诉分类三维度标准 |
| 《个人信息保护法》 | PII 最小必要；脱敏展示；访问留痕 |
| 《生成式人工智能服务管理暂行办法》 | AI 生成内容标识；不得生成虚假信息 |

注意：法规时效性须核对，引用时标注文件版本和生效日期；征求意见稿与正式稿须区分标注。
